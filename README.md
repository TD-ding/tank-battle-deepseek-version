# 坦克大战 deepseek-version

经典坦克大战游戏，基于 HTML5 Canvas 实现。

## 简介

一款经典的俯视角坦克射击游戏。玩家控制坦克在迷宫中移动，消灭所有敌方坦克即可过关。

## 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+)
- 无需任何外部依赖

## 目录结构

```
tank-battle-deepseek-version/
├── index.html    # 游戏主文件（HTML + CSS + JS）
└── README.md     # 项目说明
```

## 如何运行

直接用浏览器打开 `index.html` 即可开始游戏。

```bash
# 或者用 Python 启动本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作说明

| 按键 | 功能 |
|------|------|
| ↑↓←→ | 移动坦克 |
| 空格 | 射击 |
| R | 重新开始 |
